# HTML Composition And Rendering Procedure

Use this reference for HTML scenes, composition inputs, layout validation, and
rendering to the approved video target.

## Required Authority

Locate the accepted composition schema, scene ordering, dimensions, duration
ownership, asset policy, browser/render target, and output codec contract.
Do not select these product-visible properties from framework defaults.

## Implementation

- Build scenes from validated provider-neutral generation results.
- Keep content data separate from rendering mechanics where the accepted design
  requires repeatable composition.
- Resolve local assets through repository-approved paths and storage rules.
- Make scene timing consume finalized timeline data rather than guessed speech
  duration.
- Preserve deterministic fixtures that can render without live provider calls.

## Proof

- Run available HTML lint and layout inspection.
- Render the smallest representative composition required by the task.
- Inspect the rendered output, not source alone.
- Measure resolution, duration, frame/codec properties, clipping, overflow, and
  missing assets when required by the accepted contract.

Stop when scene schema, render target, asset handling, timeline ownership, or
acceptance oracle is unresolved.
