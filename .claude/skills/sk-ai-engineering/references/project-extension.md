# Repository-Specific Extension

This reference routes to procedures that are specific to this repository. They
do not narrow the reusable `sk-ai-engineering` capability contract.

Read only the procedure required by the approved work package:

- `html-composition.md` for browser composition and render behavior;
- `speech-timeline.md` for speech generation, caching, and timeline alignment;
- `artifact-contract.md` for generated artifact metadata and provenance.

Repository requirements and accepted architecture remain authoritative. Stop
when a project-specific behavior or quality threshold is not defined.
